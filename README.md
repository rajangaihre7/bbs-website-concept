# Beckenham Building Supplies – website concept

A design concept for a new Beckenham Building Supplies website, prepared as a pitch.
This is **not** the official BBS website. The live site is https://www.bbsupplies.co.uk/.

The site is a single `index.html` with seven pages (Home, Building supplies, Plumbing & bathrooms,
Paint & decorating, Delivery, About us, Contact). It is hidden from search engines (`noindex` and `robots.txt`).
